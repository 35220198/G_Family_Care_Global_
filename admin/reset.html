Reset your password

L&F Medical Clinic · Administrator

This site is static (GitHub Pages), so there is no email reset. The administrator password is a SHA-256 hash stored in js/admin-auth.js. Change it by replacing that hash — the password itself is never stored anywhere.

  1. Open js/admin-auth.js in your GitHub repository.
  2. Find the line passwordHash: '…'.
  3. Generate a new hash with the local tool below (or any SHA-256 tool).
  4. Paste the new 64-character hash in place of the old one and commit.
  5. GitHub Pages redeploys in about a minute — sign in with the new password.
