Reset your password

G.Family Home Care Services

Email-based reset is not enabled yet. Until an email service is connected, the administrator password is changed directly in Cloudflare — which is safer, because the password never touches the website files.

  1. Open the Cloudflare dashboard and go to Workers & Pages, then your project.
  2. Go to Settings → Variables and secrets.
  3. Edit ADMIN_PASSWORD and enter your new password.
  4. Open Deployments and choose Retry deployment on the newest one.
  5. Return to the login page and sign in with the new password.

Prefer not to store a plain password? Open the hashing tool, generate a value, save it as ADMIN_PASSWORD_HASH, then delete ADMIN_PASSWORD.
